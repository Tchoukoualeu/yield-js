# yield-js

Playground for testing [`typescript-result`](https://www.npmjs.com/package/typescript-result).

## Setup

```bash
npm install
```


## Run files

```bash
npm run divide
npm run demo
npm run all-values
npm run to-tuple
npm run calculate-stuff
npm run on-success-failure
npm run api-handler
```

Run any TypeScript file:

```bash
npm run ts -- divide.ts
npm run ts -- typescriptResultDemo.ts
npm run ts -- allValues.ts
npm run ts -- toTuple.ts
npm run ts -- calculateStuff.ts
npm run ts -- onSuccessOnFailure.ts
npm run ts -- apiHandler.ts
```
